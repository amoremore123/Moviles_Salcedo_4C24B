# Prompts de TECSUP Fit

Registro breve de prompts usados para mejorar la aplicación de reservas de gimnasio TECSUP Fit.

## 1. Login

"Mejora el login de TECSUP Fit para que se vea claro y permita validar correo y contraseña."

## 2. Clases

"Muestra en TECSUP Fit una lista de clases con nombre, horario, nivel e instructor."

## 3. Recomendación

"Agrega una recomendación sencilla de clase según el objetivo elegido por el usuario: energía, fuerza o movilidad."

## 4. Reservas

"Permite seleccionar una clase, elegir un horario y confirmar la reserva en TECSUP Fit."

## 5. Navegación

"Organiza TECSUP Fit con pantallas para inicio, reservas, rutinas, perfil y detalle de clase."

## 6. Explicación

"Explica de forma sencilla cómo funciona el flujo de reserva de una clase en TECSUP Fit."
